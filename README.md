# -voting-power-analysis
A game-theoretical analysis of voting power in the UNSC, IMF, and GST Council using the Banzhaf and Shapley–Shubik Power Indices.

## Overview

This research dissertation examines weighted voting systems from a
game-theoretical perspective, focusing on the distinction between
formal voting weight and actual voting power.

The study applies the Banzhaf Power Index and Shapley–Shubik Index
to analyze voting structures in:

- United Nations Security Council
- International Monetary Fund
- GST Council

## Research Questions

1. Does formal voting weight accurately reflect actual voting power?
2. How does the distribution of voting power differ across institutions?
3. What role do veto rights and voting quotas play in determining
   effective influence?

## Methodology

The analysis uses cooperative game theory and weighted voting games.
Voting power is evaluated using:

- Banzhaf Power Index
- Shapley–Shubik Index

## Key Concepts

- Weighted voting games
- Pivotal players
- Veto power
- Voting quotas
- Banzhaf Power Index
- Shapley–Shubik Index
